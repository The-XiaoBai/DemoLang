# Changelog

All notable changes to DemoLang are documented here.

## Current Changes

- **REPL** (`Shell`) and **file execution** (`FileLoader`)
- **Data types**: Integer (64-bit), Float (80-bit), String (UTF-8), List
- **Operators**: arithmetic (`+`, `-`, `*`, `/`), comparison (`==`, `!=`, `>`, `<`, `>=`, `<=`), logical (`&`, `|`, `!`), return (`@`)
- **Variables**: dynamic typing, reassignable across types
- **Functions**: lambda syntax with default parameters, first-class functions
- **Control flow**: If (`?`/`??`/`:`), While (`^`), Continue (`#`), Break (`##`)
- **Built-in functions**: `print()`, `exit()`, `query()`
- **Error handling**: three-phase detection (Lexer → Parser → Runtime)
- **Tests**: operators, variables, literals, control flow, functions, lists, errors, integration, and utils
